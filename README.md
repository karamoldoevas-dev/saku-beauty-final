# SAKU BEAUTY — Luxury Beauty E-Commerce

Учебный проект: интернет-магазин премиальной косметики на **React**.

## Возможности

- Главный экран с анимированной розой (движется за мышью, по клику падают лепестки); на телефоне — фото на весь экран
- Каталог из 12 товаров, фильтр по категориям, поиск, избранное
- Страница товара: описание, состав, польза, способ применения, выбор количества
- Корзина: добавление, удаление, количество, суммы, бесплатная доставка от 8 000 сом
- Оформление заказа и **демо-оплата** (MBank, O!Bank, Simbank, демо-карта) — реальные деньги не списываются
- История заказов
- Хиты продаж, новинки, коллекции, «Почему выбирают нас», отзывы, подписка на новости
- 3 языка: **RU / KG / EN**
- Дневная и ночная тема — автоматически по настройке телефона или ПК
- Звуки (Web Audio API) с кнопкой выключения
- Адаптивный дизайн: телефон, планшет, компьютер
- Корзина, избранное, язык и заказы сохраняются в **localStorage**

## Технологии

React 18 · Vite · Framer Motion · Lucide React · CSS

## Запуск

```bash
npm install
npm run dev
```

## Структура

```
src/
├── App.jsx              главный компонент: шапка, состояние, сборка страницы
├── data.js              переводы RU/KG/EN и список товаров
├── details.js           состав и польза товаров
├── sections.js          отзывы и «Почему выбирают нас»
├── sound.js             звуки
├── styles.css           стили, тёмная тема, адаптив
└── components/
    ├── Hero.jsx         главный экран с розой
    ├── ProductCard.jsx  карточка товара
    ├── Product.jsx      окно товара
    ├── Cart.jsx         корзина и демо-оплата
    ├── Sections.jsx     хиты, новинки, отзывы
    ├── Banner.jsx       рекламная лента
    ├── Promo.jsx        акции
    └── Art.jsx          фото товара
public/photos/           фотографии
```

> Фотографии используются в учебных целях.
